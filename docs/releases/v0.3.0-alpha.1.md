# DevSift v0.3.0-alpha.1

This is DevSift's first public pre-release artifact. It packages the read-only
command-line interface completed through Phase 7 as one universal macOS binary.

## Included

- `devsift status` and `devsift --version`;
- read-only `devsift scan` text and JSON output;
- read-only `devsift classify` text and JSON output;
- `arm64` and `x86_64` slices with a macOS 14 deployment floor.

The source repository also contains Core-internal, npm-only quarantine and
manual restore kernels. They are not public API and are not reachable from any
command in this archive. The release contains no cleanup, restore, purge, or
delete command.

## Run from the extracted directory

```shell
tar -xzf devsift-0.3.0-alpha.1-macos-universal.tar.gz
cd devsift-0.3.0-alpha.1-macos-universal
./devsift --version
./devsift status
```

The binary is not Developer ID signed and is not Apple notarized. Its ad-hoc
signature verifies file integrity on macOS but does not identify the publisher.
Gatekeeper or organizational security policy may require a separate explicit
decision. Do not disable Gatekeeper globally.

## Verify the download

From the directory containing the release archive and `SHA256SUMS`:

```shell
shasum -a 256 -c SHA256SUMS
gh attestation verify \
  devsift-0.3.0-alpha.1-macos-universal.tar.gz \
  --repo jxewonkim/devsift \
  --signer-workflow jxewonkim/devsift/.github/workflows/release.yml \
  --source-ref refs/tags/v0.3.0-alpha.1 \
  --deny-self-hosted-runners
```

The checksum detects corruption or the wrong file. The GitHub attestation binds
the archive digest to the tag workflow and repository identity.

## Known limitations

- The SwiftUI executable remains source-only; there is no distributed `.app`.
- There is no Developer ID signature, notarization, installer, Homebrew formula,
  or automatic updater.
- DevSift is pre-alpha. Its public Swift API and output contracts may change
  before 1.0; versioned JSON and journal contracts change only through their
  documented compatibility rules.
